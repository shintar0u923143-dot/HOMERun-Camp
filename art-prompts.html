HOMERun Camp Art Sheets

Each prompt makes one image on magenta, sometimes with several pieces (all the runner poses, all the trees). I cut them apart and name them for the game. Obstacles only need one straight-from-behind view: the game uses it in all three lanes, because with this camera the side lanes are only about 5 degrees off-centre.

Steps: click Copy, paste into Gemini, set the aspect ratio shown on the green label if Gemini lets you, then send me the result with its name (for example "sheet-obs-van"). Start with Phase 1 so we can check the look early.

If a sheet comes out messy (views touching or overlapping), just ask Gemini "same image, but with more magenta space between them".
